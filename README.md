# НИР: оценка эффективности детектирования кибератак

Репозиторий содержит материалы и программный прототип научно-исследовательской работы по количественной оценке фактической эффективности детектирования кибератак.

## Цель

Разработать и экспериментально проверить метод, который сопоставляет заявленное покрытие техник MITRE ATT&CK с результатами контролируемых атак и качеством доступной телеметрии.

В отличие от статической карты правил, итоговая оценка должна учитывать:

- наличие необходимых источников телеметрии и полей событий;
- фактическое срабатывание или несрабатывание детекторов;
- ложноположительные и ложноотрицательные результаты;
- время обнаружения;
- стоимость ручной проверки аналитиком.

## Планируемый результат

Программный прототип будет принимать описание тестов, события телеметрии и результаты срабатываний, а затем рассчитывать метрики покрытия и формировать сравнительный отчёт.

Основные метрики: precision, recall, F1, взвешенное покрытие техник, время обнаружения и трудозатраты на проверку.

## Структура

```text
data/          описание входных и экспериментальных данных
docs/          план и текстовые материалы НИР
experiments/   сценарии и результаты контролируемых экспериментов
sources/       нормативные, научные и технические источники
src/           исходный код прототипа
tests/         автоматические тесты
```

## Предполагаемый стек

- Python 3.11+
- FastAPI и Pydantic
- Pandas и scikit-learn
- PostgreSQL
- pytest
- Plotly или Streamlit
- Docker Compose

Инструменты испытательного стенда могут включать Wazuh или Elastic, Sysmon, auditd, Suricata, Sigma и Atomic Red Team.

## Быстрый старт

Проект находится на начальном этапе. После появления первой версии прототипа здесь будут добавлены команды установки, запуска и воспроизведения экспериментов.
